
**Prompt for Agentic AI: Kashmiri Carpets Auction House Website**

**1. Project Goal**

Create a fully functional, visually appealing React-based frontend for a decentralized Kashmiri carpet NFT marketplace and auction house. The website will interact with a set of smart contracts deployed on a local dual-chain (L1 and L2) Ethereum environment.

**2. Core Features**

*   **Wallet Integration:**
    *   Allow users to connect their Ethereum wallets (e.g., MetaMask).
    *   Display the user's connected address and FAKEBTC balance.
    *   Provide a mechanism for the user to switch between the L1 and L2 networks.

*   **User Registration:**
    *   A simple form for users to register as sellers by calling the `registerSeller` function on the `UserRegistry` contract.

*   **NFT Minting:**
    *   A form for registered sellers to mint new Kashmiri carpet NFTs.
    *   The form should allow uploading an image (which will be stored locally in the frontend for this demo) and entering metadata (name, description).
    *   The minting process will call the `mint` function on the `CarpetNFT` contract.

*   **NFT Gallery & L1 Marketplace:**
    *   A main gallery page displaying all minted carpet NFTs.
    *   Each NFT in the gallery should be a card showing its image, name, and owner.
    *   Clicking on an NFT should lead to a detail page with larger image, full description, and owner address.
    *   If the connected user is the owner of the NFT, the detail page should have a "List for Sale" button.
    *   The "List for Sale" button should open a modal where the owner can set a price in FAKEBTC and list the NFT for direct sale on the L1 `Marketplace` contract.
    *   If an NFT is listed for sale, the detail page should show the price and a "Buy Now" button for other users.
    *   The "Buy Now" button should trigger the purchase transaction on the L1 `Marketplace`.

*   **L2 Auction House:**
    *   On the NFT detail page, if the user is the owner, there should also be a button to "Start Auction" on L2.
    *   This button should open a modal to set a minimum bid and duration for the auction, which will be created on the L2 `AuctionHouse` contract.
    *   A separate "Auctions" page should display all active auctions with countdown timers.
    *   Each auction should have a detail page where users can see the carpet, current highest bid, and place new bids.

*   **FAKEBTC Faucet:**
    *   A simple button to get FAKEBTC tokens for testing purposes by calling the `faucet` function on the `FAKEBTC` contract.

**3. Technical Stack**

*   **Framework:** React (using functional components and hooks) with TypeScript.
*   **Styling:** Use a modern CSS framework like Material-UI or Bootstrap for a clean and responsive layout.
*   **Blockchain Interaction:** Use the `ethers.js` library (version 6.x).

**4. Smart Contract Integration**

The project uses a dual-chain architecture:
*   **L1 (Local Hardhat Node on port 8545, chainId 31337):** For NFT minting, direct sales (Marketplace), and final settlement (Bridge).
*   **L2 (Local Hardhat Node on port 9545, chainId 31338):** For running auctions (AuctionHouse).

**Contract Addresses:**
The deployed contract addresses are located in `frontend/public/deploy-addresses.json`. The frontend should fetch this file to get the addresses. The structure of the file is:
```json
{
  "l1": {
```

**6. Component Structure (Suggestion)**

*   `App.tsx`: Main component, handles routing.
*   `components/`:
    *   `Header.tsx`: Contains navigation links and the `WalletConnector` component.
    *   `WalletConnector.tsx`: Handles wallet connection and network switching.
    *   `NFTGallery.tsx`: Displays all NFTs.
    *   `NFTCard.tsx`: A single card in the gallery.
    *   `NFTDetail.tsx`: Detail page for an NFT, with options to sell or auction.
    *   `AuctionList.tsx`: Displays all active auctions.
    *   `AuctionDetail.tsx`: Detail page for an auction, with bidding functionality.
    *   `MintForm.tsx`: Form for minting new NFTs.
    *   `Faucet.tsx`: The FAKEBTC faucet button.
    *   `UserRegistryForm.tsx`: The user registration form.
